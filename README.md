# Laboratorio 2 - Text Mining & Image Recognition

## Descripción

Este repositorio contiene la implementación del Laboratorio #2 del curso
Text Mining & Image Recognition de la Maestría en Business Intelligence.

Se desarrollan diferentes técnicas de procesamiento digital de imágenes utilizando
Python, OpenCV y NumPy.

## Tecnologías utilizadas

- Python
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## Ejercicios realizados

### Ejercicio 1
Binarización de imágenes.

### Ejercicio 2
Operaciones entre imágenes:
- Suma
- Resta
- AND
- OR
- XOR

### Ejercicio 3
Representación 3D de una imagen en escala de grises.

### Ejercicio 4
Transformaciones:
- Negativa
- Lineal
- Logarítmica
- Exponencial

### Ejercicio 5
Aplicación de filtros convolucionales:
- Gaussiano
- Sobel
- Sharp
- Unsharp
- Laplaciano

### Ejercicio 6
Comparación entre filtro Laplaciano y detector Canny.

### Ejercicio Extra
Evaluación automática de necesidad de ecualización de histograma.
